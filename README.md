# Skills Manager

Joel 的 ZTools AI Skill 管理插件。支持本地技能库、GitHub 仓库安装、发行附件和发行版源码快照。

## 安装

在 GitHub Releases 下载 `.zpx`，通过 ZTools 插件管理的“导入本地插件”安装。应用 ID 为 `ai-skills-manager`，同 ID 的原版会被视为升级。升级前请备份插件和用户主目录下的 `.ai-skills-manager/registry.json`。

## 功能

- 浏览本地 AI 工具的 Skill，支持筛选、卡片/列表和仓库分组。
- 点击卡片的“说明”查看本地 README，没有时回退到 SKILL.md；只读原始文本。
- 粘贴 GitHub 仓库链接，优先选择作者上传的 ZIP；也可选择指定发行版本的源码快照。
- 没有合适发行包时，明确选择当前仓库源码；源码模式仍会浅克隆整个仓库。
- 下载、解包、安装分阶段显示进度；未知总量使用等待状态。
- 发行安装按版本/附件更新，确认已是最新版时提示并跳过下载。
- 异步安装先准备文件、备份旧目录再替换，失败尝试回滚；不复制 `.git`。
- 刷新会清除缓存并重新扫描本地目录。

## 更新规则

作者上传的发行附件按最新正式版的同名附件匹配。附件改名时要求重新选择，不自动切换来源。发行源码快照按发行标签更新。Git 来源重新克隆并匹配 Skill 名称，暂不根据提交版本跳过下载。刷新仅扫描本地，不检查远端。

## 安全与限制

只接受 GitHub 官方 HTTPS 下载，保留证书校验；不自动使用第三方镜像。ZIP 限制为 50 MiB 下载、100 MiB 展开、10 MiB 单文件及 20000 条目，拒绝越界路径和符号链接。支持经过验证的小型 ZIP64。安装保留 `.skill-backup-*`，确认新版本正常后自行清理。此机制不合并本地修改。

原有卸载会删除 Skill，执行前请确认。重要文件请自行备份。源码快照不是作者精简安装包，可能包含整个仓库。当前不支持任意勾选文件后安装。

## 开发与打包

需要 Node.js 22.12+，推荐 Node 24。执行 `npm install`、`npm test`、`npm run lint`、`npm run verify:ui`、`npm run pack`。UI 验证默认使用本机 Edge，宿主接口为模拟数据；实际 ZTools 仍需手动验证。插件目录 `plugin/plugin.json` 可作为开发插件入口。

当前从作者提供的 1.0.1 编译产物继续维护，仓库保留原前端 bundle；新增模块和测试为可编辑源码。完整 Vue 工程尚未包含，未宣称已恢复原源码。

## 第三方组件

JSZip 保留于 `plugin/vendor`，许可见 `plugin/vendor/JSZip-LICENSE.txt`。其他前端依赖仍包含在原始编译 bundle 中。本仓库暂未指定新的整体开源许可证；公开可访问不等于授予任意再分发许可。
